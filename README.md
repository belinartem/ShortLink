Link Shortener — это простой сервис для сокращения URL-адресов. Он позволяет пользователям создавать короткие ссылки, которые перенаправляют на длинные URL-адреса. Сервис также отслеживает количество переходов по каждой ссылке и автоматически удаляет просроченные ссылки.

  Как пользоваться сервисом
1. Запустите приложение: java LinkShortener
2. После запуска приложение автоматически создаст короткую ссылку для указанного длинного URL. В примере используется URL https://ru.stackoverflow.com
3. Вы можете использовать созданную короткую ссылку для перехода на длинный URL. Приложение отслеживает количество переходов и выводит сообщения о перенаправлении.
4. Ссылка будет активна до тех пор, пока не будет достигнуто максимальное количество кликов или пока не истечет срок действия.

  Поддерживаемые команды
В текущем сервисе поддерживаются следующие команды:
1. Сокращение ссылкм: 
Метод shortenLink(String longUrl, String userId, int maxClicks, int lifetimeInSeconds) принимает длинный URL, идентификатор пользователя, максимальное количество кликов и время жизни ссылки в секундах.
2. Редирект на длинный URL:
Метод redirect(String shortUrl) выполняет перенаправление по короткой ссылке.
3. Удаление просроченных ссылок
Сервис автоматически удаляет ссылки, срок действия которых истек, каждые 1 минуту.
